Appendix C: Implementation notes

This appendix collects the differences between the implementations that the book mentions: ga68, the Algol 68 front end of GCC; a68j, which compiles the same language to the Java virtual machine; and Algol 68 Genie (a68g), an interpreter that many Algol 68 programs on the web, among them most Rosetta Code programs, are written for. The information describes the versions used for this book, which the preface lists.

Notation

ga68 and a68j Algol 68 Genie
reserved words lower case: begin int upper case: BEGIN INT
declared type names capitalized: Node upper case: NODE
word operators upper case: ABS upper case: ABS
names lower case, underscores: max_int lower case, blanks allowed: max int
comments { ... } (nested) # ... #, CO ... CO, COMMENT ... COMMENT
program a block or other enclosed construct the same, or a sequence without brackets

Converting a program from one notation to the other is mechanical: the reserved words and the type names change case, blanks in names become underscores, and comments get the other brackets. A name that is a reserved word in ga68 but not in Algol 68 Genie, such as in, out, empty, word or op, must be renamed.

Sizes

ga68 and a68j Algol 68 Genie
int 32 bits 64 bits
long int 64 bits 128 bits
long long int 64 bits 72 decimal digits
real 32 bits 64 bits
long real 64 bits 128 bits
long long real 80 bits (ga68), 64 bits (a68j) 63 decimal digits
bits 32 64

A program written for Algol 68 Genie that relies on 64-bit int values must use long int with ga68 and a68j. Since real has only about seven decimal digits in ga68 and a68j, numerical programs should use long real there.

Transput

ga68 and a68j have no transput of the Report in their standard library. The module Genie_Transput, which comes with a68j and can be compiled with ga68, provides unformatted transput: print, read, put, get, files on disk, files associated with strings, the layout procedures and the events for the end of the file and for value errors. It does not provide formats, binary transput, or the printing of records, compl, short and long long values. Algol 68 Genie provides the transput of the Report almost completely, and adds eof and eoln, which Genie_Transput also has; Section 9.12 lists what it lacks.

Printing numbers

print writes an int in a field of int_width + 1 characters with its sign, so the output of ga68 and a68j is narrower than that of Algol 68 Genie. A real is written in floating-point notation with real_width digits. Programs whose output should not depend on the implementation use whole and fixed.

When ga68 and a68j convert a real to a string, the last of its seven digits is sometimes wrong (9.81 is printed as 9.810001); the examples of this book avoid such values.

Running Rosetta Code programs

Most Algol 68 programs on Rosetta Code are written for Algol 68 Genie in upper-case notation. To run one with ga68 or a68j, convert the notation as above, add access Genie_Transput and an enclosing block if the program has none, and check whether it relies on 64-bit integers, on formats or on the other features in the table above.
