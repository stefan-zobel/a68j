4 Arrays and records

The values of the previous chapters were single numbers, characters and truth values. Real programs work with collections of values: a list of measurements, a matrix, a table of names and dates. Algol 68 provides two ways of building such values. An array holds a number of values of the same type, selected by position; a record holds a fixed set of values of possibly different types, selected by name. Both can be combined freely: arrays of records, records containing arrays, arrays of arrays. This chapter also introduces type declarations, which give a name to a type.

4.1 Arrays

An array variable is declared by giving its bounds in square brackets before the element type:

[1:5] int squares;
for i from LWB squares to UPB squares do squares[i] := i * i od;
print ((squares, newline));
print ((squares[3], " ", LWB squares, UPB squares, newline));
[0:2] char letters;
letters[0] := "x"; letters[1] := "y"; letters[2] := "z";
print ((letters[0], letters[2], newline))
         +1         +4         +9        +16        +25
         +9          +1         +5
xz

The declaration [1:5] int squares allocates five cells for int values, numbered 1 to 5. Unlike in C, Java or Python, the numbering need not start at 0 or 1: [0:2] char letters has the indices 0, 1 and 2, and an array of the years 1990 to 2025 could be declared as [1990:2025] real. The lower bound is the first number and the upper bound the second; the operators LWB and UPB give them. A loop over all elements should use them rather than repeat the numbers. If the lower bound is 1, it can be left out: [n] real means [1:n] real.

An element is selected by an index in square brackets, as in squares[3]. The Report calls an array a multiple value or row, and the selection of an element a slice.

The bounds are evaluated when the declaration is carried out, so the size of an array can depend on input. The following program reads a count and then that many numbers:

int n = read_int;
[n] real values;                     { the same as [1:n] real values }
for i to n do values[i] := read_real od;
real sum := 0;
for i to n do sum +:= values[i] od;
print (("mean of ", whole (n, 0), " values: ", fixed (sum / n, 0, 3), newline))
mean of 4 values: 3.000

The input was:

4
2.5 3.5
1.0 5.0

Once declared, the array keeps its bounds; an array that can grow or shrink is the subject of Chapter 7. Every index is checked: an index outside the bounds stops the program with an error.

access Genie_Transput
begin
   [1:3] int a := (10, 20, 30);
   int i := 4;
   print ((a[i], newline))
end
out-of-bounds.a68:5: runtime error: bound 4 out of range [1:3]

4.2 Array literals

A list of values in parentheses, separated by commas, is an array literal (row display) wherever an array is expected. A constant array can take its bounds from the literal: the declaration [] int primes = (2, 3, 5, 7, 11) gives no bounds, and primes has the bounds 1 to 5. The Report calls a type written without bounds, such as [] int, a formal declarer; one with bounds, as in the declaration of a variable, an actual declarer.

[] int primes = (2, 3, 5, 7, 11);
[] real weights = (1, 0.5, 0.25);         { each int is widened }
[] int none = ();
print ((UPB primes, UPB weights, UPB none, newline));
[1:3] int v := (7, 8, 9);
v := (1, 2, 3);                           { replaces all elements }
print ((v, newline))
         +5         +3         +0
         +1         +2         +3

The elements of a literal are converted to the element type where necessary, so the integers of weights are widened to real. The empty literal () gives an array with the bounds 1 to 0, that is, with no elements. A literal can also be assigned to an array variable, which replaces all its elements. A literal always has the lower bound 1, so its bounds match those of the variable only if the variable has the lower bound 1 and as many elements as the literal. For a variable [0:2] int w, the assignment w := (1, 2, 3) fails, but w[@1] := (1, 2, 3) works: w[@1] is the whole of w, renumbered to start at 1 (Section 4.5).

4.3 Arrays are values

An array in Algol 68 is a value, like a number. Assigning one array variable to another copies the elements:

[1:3] int a := (1, 2, 3), b;
b := a;                     { copies the elements }
b[1] := 99;
print ((a[1], b[1], newline))
         +1        +99

After the assignment, a and b are separate arrays; changing b does not change a. This is the behavior of arrays in C when they are inside a struct, or of the arrays of Fortran, but not that of Java, Python or JavaScript, where an assignment makes two names refer to the same array. In Algol 68, two names refer to the same array only if a reference to it is shared explicitly (Chapter 7). A constant declared with an array value, [] int c = b, is a copy as well: later changes of b do not show in c. The same holds for a parameter of type [] int (Chapter 5).

Implementation note.  Algol 68 Genie does not always copy: if a procedure has a [] int parameter and a ref [] int parameter, and both are given the same array, a change through the reference shows in the value parameter during the call. ga68 and a68j copy, as the Report requires.

Since an array variable has fixed bounds, an assignment must supply an array with the same bounds. A mismatch is detected when the program runs:

access Genie_Transput
begin
   [1:3] int a;
   [1:4] int b := (1, 2, 3, 4);
   a := b;
   print ((a, newline))
end
bounds-mismatch.a68:5: runtime error: multiple bounds mismatch in assignation: dim 1: [1:3] /= [1:4]

4.4 Multi-dimensional arrays

An array can have several dimensions; the bounds of each dimension are separated by commas, and so are the indices:

[1:2, 1:3] int m := ((1, 2, 3),
                     (4, 5, 6));
print ((whole (1 UPB m, 0), " rows, ", whole (2 UPB m, 0), " columns", newline));
for i to 1 UPB m do
   for j to 2 UPB m do print (whole (m[i, j], -4)) od;
   print (newline)
od
2 rows, 3 columns
   1   2   3
   4   5   6

1 UPB m is the upper bound of the first dimension and 2 UPB m that of the second; plain UPB m means 1 UPB m. A literal for a two-dimensional array is a list of rows, each of which is a list.

An array of arrays is something different: [] [] int is an array whose elements are themselves arrays, and those may have different lengths, as in ((1), (2, 3), (4, 5, 6)). Its elements are selected with two pairs of brackets, x[3][2]. A two-dimensional array, by contrast, is always rectangular.

4.5 Slices

An index range in place of an index selects a part of an array, a slice:

[1:6] int a := (10, 20, 30, 40, 50, 60);
print ((a[2:4], newline));
print ((LWB a[2:4], UPB a[2:4], newline));        { bounds 1 to 3 }
print ((LWB a[2:4 @ 2], UPB a[2:4 @ 2], newline)); { bounds 2 to 4 }
print ((a[:2], " ", a[5:], newline));
a[1:3] := (0, 0, 0);                               { assigns into a }
print ((a, newline))
        +20        +30        +40
         +1         +3
         +2         +4
        +10        +20         +50        +60
         +0         +0         +0        +40        +50        +60

The slice a[2:4] consists of the elements 2 to 4 of a, but its own bounds are 1 to 3: a range is renumbered from 1 unless a new lower bound is given after @, as in a[2:4 @ 2]. Either end of the range can be left out; it then defaults to the corresponding bound of the array. The Report calls an index range a trimmer.

A slice of an array variable is not a copy: it refers to the elements of the original array, so an assignment to the slice changes the array, as the last line shows. In the terms of Section 2.6, the slice of a reference to an array is a reference to part of the array. An assignment between overlapping parts of an array is safe, since the right-hand side is a value that is complete before anything is stored:

[6] int a := (1, 2, 3, 4, 5, 6);
a[2:6] := a[1:5];               { shift right by one place }
print ((a, newline))
         +1         +1         +2         +3         +4         +5

shifts the elements one place to the right, which in C would need memmove rather than memcpy.

In a multi-dimensional array, an index can be given for some dimensions and left out for others. Leaving out the second index of a matrix selects a row, leaving out the first selects a column:

[1:3, 1:3] int m := ((1, 2, 3), (4, 5, 6), (7, 8, 9));
print ((m[2, ], newline));             { the second row }
print ((m[, 3], newline));             { the third column }
m[, 1] := (0, 0, 0);                   { clears the first column }
print ((m[3, ], newline))
         +4         +5         +6
         +3         +6         +9
         +0         +8         +9

A dimension whose index is left out entirely keeps its bounds; only a range with a colon is renumbered:

[0:9, 2:11] int m;
print ((LWB m[1, ], UPB m[1, ], newline));        { 2 and 11: kept }
print ((LWB m[1, :], UPB m[1, :], newline));      { 1 and 10: renumbered }
print ((LWB m[1, 3:], UPB m[1, 3:], newline));    { 1 and 9 }
print ((LWB m[1, 3:10 @ 3], UPB m[1, 3:10 @ 3], newline))
         +2        +11
         +1        +10
         +1         +9
         +3        +10

For a matrix whose bounds do not start at 1, a loop over a row m[i, ] must therefore run from LWB m[i, ], not from 1.

A row or an element that a loop body uses several times can be given a name of its own. Inside a loop over i, the declaration ref [] int row = m[i, ] makes row[j] the same cell as m[i, j], so assignments to it change the matrix. For an element that is only read, int x = v[i] names its current value; this is a copy, which later assignments to v[i] do not change.

4.6 Strings are arrays

The type string is an array of characters. Strings normally have the lower bound 1; a string variable takes the bounds of whatever is assigned to it, so a slice with @ can give it another, and loops should use LWB s. Everything said about arrays applies to it: UPB s is normally its length, s[i] its i-th character, and s[2:4] a part of it:

string s = "Algol 68 report";
print ((UPB s, " ", s[1], " ", s[7:8], newline));
int vowels := 0;
for i to UPB s do
   char c = s[i];
   if c = "a" OR c = "e" OR c = "i" OR c = "o" OR c = "u" then vowels +:= 1 fi
od;
print ((vowels, newline))
        +15 A 68
         +3

Strings are compared with = and < in the order of their character codes, which is alphabetical for letters of the same case (in ASCII, every capital letter comes before every small letter), and joined with +. A string variable can hold strings of different lengths, which an ordinary array cannot; Chapter 7 explains how.

4.7 Records

A record groups values of possibly different types into one value. Its type, written with struct, lists the types and names of its fields:

struct (string name, int born, bool alive) p := ("Ada", 1815, false);
print ((name of p, " was born in ", whole (born of p, 0), newline));
born of p := 1816;                         { assigns to one field }
p := ("Grace", 1906, false);               { assigns all fields }
print ((name of p, " ", whole (born of p, 0), newline))
Ada was born in 1815
Grace 1906

The record type of p has three fields: name, a string, born, an int, and alive, a bool. A field is selected with of: name of p is what most languages write as p.name. If p is a variable, born of p is a reference to the field, so the field can be assigned to on its own. The Report calls a record a structure, a field name a field selector, and name of p a selection.

A record value can be written as a list of field values in parentheses, in the order of the fields (structure display). Such a literal needs at least two fields; a record with a single field must be built by assigning to the field.

Selection with of binds less tightly than indexing: name of class[i] means name of (class[i]), the name of the i-th element of an array of records. If a field is itself an array, parentheses are needed to index it: (marks of class[i])[k]. The same holds for a field that is a function: (f of s) (x) calls it, while f of s (x) selects the field f of s (x) and is rejected, with a message that s must yield a function.

4.8 Type declarations

Writing out a record type at each use would be tedious and error-prone. A type declaration (mode declaration) gives a type a name:

mode Point = struct (real x, y);
mode Circle = struct (Point center, real radius);
Circle c := ((0, 0), 1.5);
x of center of c := 2;
print ((fixed (x of center of c, 0, 1), " ",
        fixed (radius of c, 0, 1), newline))
2.0 1.5

The names of declared types begin with a capital letter (Section 1.4). A declared type can be used wherever a type is expected, including in other type declarations: a Circle contains a Point. The field x of center of c is the x of the center of c.

A type declaration does not create a new, distinct type; it gives a name to a type that is determined by its structure. Two record types with the same field types and field names, in the same order, are the same type, whatever they are called:

mode Meters = struct (real value, int precision);
mode Seconds = struct (real value, int precision);
Meters distance = (100, 2);
Seconds time = distance;                { allowed: the same type }
print ((fixed (value of time, 0, 1), newline))
100.0

This structural equivalence differs from the nominal typing of C, Java, Rust and most current languages, where two separately declared structs are different types even if their fields are identical. In Algol 68, a Meters and a Seconds as declared above are interchangeable, and the type system does not keep them apart. Chapter 7 returns to the question of when two types are the same.

A type declaration can also name an array type, such as mode Vector = [1:3] real. It must then give the bounds: a type without bounds, such as [] int, is allowed for a parameter or a constant, which take their bounds from a value, but not in a type declaration, since a type declaration may be used to declare variables.

4.9 Arrays of records

When the fields of an array of records are selected with of, the result is an array of fields:

mode Point = struct (int x, y);
[1:4] Point path := ((0, 0), (3, 4), (6, 0), (9, 4));
print ((x of path, newline));            { all x fields: a [] int }
y of path[2] := 5;                       { one field of one element }
print ((y of path, newline))
         +0         +3         +6         +9
         +0         +5         +0         +4

x of path is an array of the four x values. If path is a variable, it is even a reference to them, so that x of path := (1, 2, 3, 4) assigns to the x field of every element. The Report calls this multiple selection. Few current languages have it; the closest analog is selecting a column of a table in a data-frame library.

4.10 A single value as an array

Where an array is required and a single value is given, the value is converted into an array with one element, the bounds 1 to 1:

[] int single = 42;                  { a one-element array }
print ((LWB single, UPB single, single[1], newline));
print (newline)                      { a list of one item }
         +1         +1        +42

This implicit conversion is called rowing (rowing) in the Report, since an array is a row. It is why print (newline) needs only one pair of parentheses: print expects a list, and the single item newline is turned into a list of one. It is also why y of ps := 0, for an array ps of three points, fails when the program runs: 0 becomes an array with one element, which does not fit the three y fields.

4.11 Printing arrays and records

print accepts arrays of numbers, truth values and characters, and prints their elements one after the other, as the examples of this chapter show. A matrix is printed row by row, without line breaks between the rows. The Report’s print also accepts records, which it prints field by field, as long as they contain no references, functions or unions. A string field is printed as its characters, and an array of strings as its strings one after the other.

Implementation note.  Genie_Transput does not accept records in print; their fields must be printed one by one. Algol 68 Genie accepts them. All three implementations print arrays of strings.

4.12 Two complete programs

The first program sorts an array with insertion sort: each element in turn is moved to the left until the elements before it are not greater. The constant array data is copied into a variable with the same bounds, which the program then rearranges.

access Genie_Transput
begin
   { Insertion sort. }
   [] int data = (31, 41, 59, 26, 53, 58, 97, 93, 23, 84);
   [LWB data : UPB data] int a := data;
   for i from LWB a + 1 to UPB a do
      int v = a[i];
      int j := i - 1;
      while j >= LWB a andth a[j] > v do
         a[j + 1] := a[j];
         j -:= 1
      od;
      a[j + 1] := v
   od;
   for i to UPB a do print (whole (a[i], -4)) od;
   print (newline)
end
  23  26  31  41  53  58  59  84  93  97

The condition of the inner loop uses andth (Section 2.9): when j has passed the lower bound, a[j] must not be evaluated, since the index would be out of range. With AND, both operands would be evaluated and the program would stop with an index error.

The second program keeps a table of records, each with a name and three marks, and finds the student with the best average:

access Genie_Transput
begin
   { The student with the best average mark. }
   mode Student = struct (string name, [1:3] int marks);
   [] Student class = (("Ann",  (72, 85, 90)),
                       ("Ben",  (88, 79, 81)),
                       ("Cleo", (95, 91, 70)));
   real best := -1;
   int best_index := 0;
   for i to UPB class do
      int sum := 0;
      for k to 3 do sum +:= (marks of class[i])[k] od;
      real average = sum / 3;
      print ((name of class[i], ": ", fixed (average, 0, 2), newline));
      if average > best then best := average; best_index := i fi
   od;
   print (("best: ", name of class[best_index], newline))
end
Ann: 82.33
Ben: 82.67
Cleo: 85.33
best: Cleo

The record type Student has an array field with the bounds 1 to 3, and the array class takes its bounds from the literal. Note the parentheses in (marks of class[i])[k], explained in Section 4.7. The bounds in a type apply only where a variable is created: they are computed anew for each variable, and a constant of type Student takes the bounds of its value. A literal with four marks would be accepted in class, and the error would appear only when such a record is assigned to a Student variable.

Implementation note.  ga68 and a68j do not check the bounds of an array field when a record is assigned: a Student variable then holds four marks. Algol 68 Genie reports the error.

Exercises

The answers are at the end of the book.

  1. Declare an array that holds one real for each year from 1900 to 2000, and write a loop that sets all elements to 0.

  2. Given [] int a = (5, 6, 7, 8, 9), what are a[2:3], LWB a[2:3], UPB a[3:] and a[2:3 @ 0][0]?

  3. Given [1:3, 1:4] int m, what are the types and bounds of m[2, ], m[, 3] and m[2:3, 2]?

  4. After [1:3] int a := (1, 2, 3), b := (4, 5, 6), what does a := b; b[1] := 0 leave in a?

  5. Declare a type Date with fields day, month and year, and a constant for 3 November 1975.

  6. Why does name of class[1][1] not give the first character of the first name in an array class of records with a string field name? How must it be written?

  7. Given [1:10] Point ps with mode Point = struct (real x, y), write a single assignment that sets the y field of all ten points to 0.

  8. For [0:9, 2:11] int m, what are the bounds of m[1, ], m[1, 3:5] and m[ , 2]?

  9. What does a[2:5] := a[1:4] leave in [6] int a := (1, 2, 3, 4, 5, 6)?

Programming problems

  1. Read ten numbers and print them in reverse order.

  2. Read a matrix of 3 × 3 integers and print its transpose and the sum of its diagonal.

  3. Multiply two matrices whose sizes are read from the input.

  4. Use the sieve of Eratosthenes, an array of bool, to print the prime numbers below 1000.

  5. Keep a table of records of the planets (name, distance from the sun, diameter) and print them sorted by diameter.

  6. Binary search. Write a binary search for a value in a sorted array that works for any bounds, using LWB and UPB. Test it on arrays with the bounds 1 to 10, 0 to 9 and  − 5 to 4.

  7. Merging. Merge two sorted arrays into one sorted array, so that a value that occurs in both appears only once.

  8. Rotation. Rotate a square matrix by 90 degrees using row and column slices (r[ , n + 1 - i] := m[i, ]), and rotate an array by r places with slice assignments only.

  9. Game of Life. Play Conway’s Game of Life on a [0:n+1, 0:m+1] bool board whose border stays empty, so that the loop over the neighbors needs no special cases. Compute each generation into a second board and assign it to the first.

  10. Generalized Fibonacci. In the Fibonacci numbers of order m, each number is the sum of the m before it, starting with m − 1 zeros and a one. Print the first 30 for a given m, keeping only the last m numbers in an array [0 : m - 1] int indexed with MOD.

  11. League table. Read the results of the games of a league, keep a table of records (team, games, points, goals for and against), and print it sorted by points, then by goal difference.
