5 Functions and operators

A program of any size is built from parts that each solve one task and that can be used again: functions. In Algol 68, a function is a value like a number or an array. It has a type, it can be bound to a name, stored in a variable, passed to another function and returned from one. The Report calls a function a procedure; this book uses both words, since Algol 68 programs declare functions with the reserved word proc.

The second half of the chapter shows how a program defines operators of its own. Operators are functions with a different calling syntax, and they make it possible to extend the arithmetic of the language to new types, such as fractions or vectors.

5.1 Declaring functions

A function declaration gives the function a name, its parameters with their types, its result type and its body:

proc max = (int a, b) int: (a > b | a | b);
proc hypotenuse = (real a, b) real: sqrt (a * a + b * b);
proc greet = (string name) void:
   print (("Hello, ", name, "!", newline));
print ((max (3, 7), " ", fixed (hypotenuse (3, 4), 0, 1), newline));
greet ("Algol")
         +7 5.0
Hello, Algol!

The declaration proc max = (int a, b) int: (a > b a | b)| has the same form as the constant declarations of Chapter 2: a name, an equals sign and a value. The value is a function literal (routine text), the part (int a, b) int: (a > b a | b)|. It lists the parameters in parentheses, then the result type, a colon and the body, which is a single expression, usually a block. The type of max is proc (int, int) int, the type of functions that take two int values and return an int. Parameters of the same type can share the type, as in (int a, b); parameters of different types are separated by commas: (string s, int n).

The declaration proc max = (int a, b) int: ... is short for proc (int, int) int max = (int a, b) int: ..., which names the type in full. The short form requires a function literal on the right-hand side. A function value computed in some other way, such as a choice between two functions, needs the full type: proc (real) real f = (c sin | cos)|. The short form with such a value is rejected with a message about a missing symbol that does not point to the cause.

A function whose result is of no interest has the result type void, as greet shows. There is no return statement: the result of a function is the value of its body, which is the value of the last expression in the block. A function that must finish early jumps to a label at the end of its body (Section 3.9), which is rarely necessary since if and case yield values.

A call gives the arguments in parentheses after the name. The Report calls the parameters formal parameters and the arguments actual parameters.

5.2 Parameters

When a function is called, each parameter is bound to its argument exactly as a constant is bound to its value in a declaration: the call max (3, 7) behaves like the declarations int a = 3, b = 7 followed by the body. This explains the rules for parameters, which differ from those of most languages.

A parameter is a constant. It cannot be assigned to:

access Genie_Transput
begin
   proc countdown = (int n) void:
      while n > 0 do print (n); n := n - 1 od;
   countdown (3)
end
param-constant.a68:4:33: error: int secondary does not yield a name

A function that needs a variable for its work declares one, for example int k := n. A function that is to change a variable of its caller takes a reference to that variable as its parameter:

proc swap = (ref int a, b) void: (int t = a; a := b; b := t);
int x := 1, y := 2;
swap (x, y);
print ((x, y, newline))
         +2         +1

The parameters of swap are of type ref int. The call swap (x, y) passes the references x and y, and the assignments in the body go to the caller’s variables. In C this would be done with pointers, in C++ with reference parameters, in Pascal with var parameters. Algol 68 needs no special kind of parameter for it: the reference is an ordinary value, passed like any other.

Both kinds of parameter can be arrays. A parameter of type [] real accepts an array of real with any bounds, and the function finds them with LWB and UPB. A parameter of type ref [] real accepts an array variable, whose elements the function can then change:

proc sum = ([] real v) real:
begin
   real s := 0;
   for i from LWB v to UPB v do s +:= v[i] od;
   s
end;
proc scale = (ref [] real v, real factor) void:
   for i from LWB v to UPB v do v[i] *:= factor od;
[0:3] real w;
w[@1] := (1, 2, 3, 4);
scale (w, 10);
print ((fixed (sum (w), 0, 1), " ", fixed (sum ((0.5, 0.25)), 0, 2), newline))
100.0 .75

The second call of sum passes an array literal. Since a literal has the bounds 1 to n, the function sees those bounds; for the variable w, it sees the bounds 0 to 3.

A function can also return a reference to a cell that already exists, such as an element of an array it receives by reference. Its call can then stand on the left of an assignment, as in C++ a function that returns a reference:

proc max_elem = (ref [] real a) ref real:
begin
   int k := LWB a;
   for i from LWB a + 1 to UPB a do
      if a[i] > a[k] then k := i fi
   od;
   a[k]
end;
[4] real v := (3, 9, 4, 1);
max_elem (v) := 0;
max_elem (v) *:= 10;
for i to 4 do print ((fixed (v[i], 0, 1), " ")) od;
print (newline)
3.0 .0 40.0 1.0

The parameter must be a ref [] real. With [] real a, the element a[k] would be a value, not a cell of the caller’s array, and could not be returned as a ref real.

5.3 Functions without parameters

A function may have no parameters. Its type is then proc int (or proc void, and so on), and its literal has no parameter list: int: expression. Such a function is called simply by writing its name; no empty parentheses are needed, or even allowed:

int seed := 1;
proc next = int: (seed := seed * 75 MOD 65537; seed);
int a = next;              { next is called: no parentheses needed }
int b = next;
print ((a, b, newline))
        +75      +5625

Writing next where an int is expected calls the function. This is another implicit conversion, which the Report calls deproceduring. Where a function itself is expected, the name is not a call: newline in a call of print is a function with a parameter, passed as a value, and print calls it at the right moment.

Each call of next changes the variable seed, so the two calls give different results. In a list such as print ((next, next)) the order of the two calls would be unspecified (Section 3.4); the program above therefore calls the function in two separate declarations.

A parameterless function whose value is discarded is called as well, which is how a function of type proc void is called as a statement. (newline is not such a function: it has a file parameter, and newline; alone does nothing; print (newline) writes a line break.) There is one exception that is easy to overlook:

proc hello = void: print (("hello", newline));
proc void p;
p := hello;           { assigns the function; nothing is called }
print (("assigned", newline));
p;                    { a name alone: the function is called }
hello
assigned
hello
hello

prints assigned and then hello twice. The assignment p := hello stores the function in the variable p and does not call it, although its value, the variable p, is discarded. A discarded assignment, a reference comparison, an allocation, a type annotation, a literal and a format are discarded as they are; any other expression that yields a function without parameters is called.

A parameter of type proc real differs from one of type real in when the argument is evaluated. A real parameter receives a value, computed once before the call; a proc real parameter receives a function, which is called at every use of the parameter:

proc twice_value = (real x) real: x + x;
proc twice_call = (proc real x) real: x + x;
int n := 0;
proc count = real: n +:= 1;
print ((fixed (twice_value (count), 0, 1), newline));
print ((fixed (twice_call (count), 0, 1), newline))
2.0
5.0

twice_value gets the value 1 and doubles it. twice_call gets the function count and calls it twice, which gives 2 and 3, and returns their sum, 5. Passing a literal such as real: v[i] * w[i] for a proc real parameter gives the effect of Algol 60’s call by name: the expression is evaluated anew at each use, with the current value of i. Algol 60 programs used this for summation functions, a trick known as Jensen’s device; in Algol 68 a parameter of type proc (int) real does the same more plainly.

5.4 Recursion

A function may call itself. The classic examples are the factorial and the Fibonacci numbers:

proc factorial = (int n) int: (n <= 1 | 1 | n * factorial (n - 1));
proc fib = (int n) int: (n < 2 | n | fib (n - 1) + fib (n - 2));
print ((factorial (10), fib (20), newline))
   +3628800      +6765

Two functions can also call each other. Since the scope of a declaration is the whole block (Section 3.3), is_even can mention is_odd before is_odd is declared. This is allowed because the call only happens later, when both declarations have been carried out:

proc is_even = (int n) bool: (n = 0 | true | is_odd (n - 1));
proc is_odd = (int n) bool: (n = 0 | false | is_even (n - 1));
print ((is_even (10), " ", is_odd (10), newline))
T F

5.5 Functions as values

A function is a value, so there are also variables that hold functions. The declaration proc (real) real f := sqrt declares a variable for functions from real to real and stores in it the square root of the standard library. A later assignment can store another function, for example a function literal written directly in the program:

proc (real) real f := sqrt;
print ((fixed (f (2), 0, 4), newline));
f := (real x) real: x * x;               { a function literal }
print ((fixed (f (3), 0, 4), newline))
1.4142
9.0000

A function literal is what other languages call a lambda or an anonymous function. Functions that take other functions as parameters are called higher-order functions. A typical example computes an integral numerically:

{ The integral of f from a to b, by the trapezoidal rule with n steps. }
proc integrate = (proc (real) real f, real a, b, int n) real:
begin
   real h = (b - a) / n;
   real sum := (f (a) + f (b)) / 2;
   for i to n - 1 do sum +:= f (a + i * h) od;
   sum * h
end;
proc bell = (real x) real: exp (-x * x);
print ((fixed (integrate (bell, -3, 3, 100), 0, 4), newline));
print ((fixed (integrate ((real x) real: x * x, 0, 3, 100), 0, 4), newline))
1.7724
9.0004

The first call passes a declared function, the bell curve e−x2, whose integral is the square root of π, about 1.7725; the second passes a literal for x2. The function in a call can itself be the result of an expression: (b sin | cos) (x)| chooses the function first and then calls it with x.

The body of a function can use the names of the blocks around it, not only its parameters. A function can thus read and change variables of the enclosing blocks:

int calls := 0;
proc counted_square = (int n) int: (calls +:= 1; n * n);
int total := 0;
for i to 4 do total +:= counted_square (i) od;
print ((total, calls, newline))
        +30         +4

Such a function is called a closure in current terminology. Algol 68 closures have a restriction that the closures of Lisp, JavaScript or Python do not have: a function may not be used after the block that declares a name it uses has ended. A function that uses a variable, a constant or a parameter of a block therefore cannot be returned from that block or stored in a variable outside it. Section 7.16 explains this rule, which is about the lifetimes of values, and how the implementations check it.

5.6 The standard functions

The standard library provides the usual mathematical functions for real arguments: sqrt, exp, ln (the natural logarithm), sin, cos, tan, arcsin, arccos and arctan, together with the constant pi. The parameterless function random returns a pseudo-random real between 0 and 1. Chapter 6 describes the library in more detail.

5.7 Defining operators

An operator is declared like a function, with op instead of proc. A binary operator has two parameters, a unary one has one. The name of an operator is either a word in capitals, such as MAX, or a symbol made of characters such as + - * / < > = and a few others. A symbol has one or two characters, and the second must be one of < > / = *; either may be followed by := or =:. A unary operator may not begin with one of these five. Thus // and +:= can be declared, but ++ cannot (“invalid operator tag”):

prio MAX = 9;
op MAX = (int a, b) int: (a > b | a | b);
op MAX = (real a, b) real: (a > b | a | b);
op SQUARE = (int n) int: n * n;
print ((3 MAX 9, " ", fixed (2.5 MAX 1.5, 0, 1), newline));
print ((SQUARE 4 + 1, " ", 2 * 5 MAX 6, newline))
         +9 2.5
        +17         +12

A binary operator needs a precedence, declared with prio (priority declaration); without it, the compiler reports an error. Here MAX gets the precedence 9, higher than that of *, so 2 * 5 MAX 6 means 2 * (5 MAX 6). A unary operator needs no precedence: like the standard unary operators, it binds more tightly than every binary operator, so SQUARE 4 + 1 is 17.

The same operator can be declared several times for different operand types; the example declares MAX for two int and for two real operands. This is overloading. The standard operators are declared in the same way in the standard library, and a program can add new meanings to them: + for vectors, * for matrices, < for dates.

The declarations of one operator in the same block must differ enough that the compiler can always tell them apart, even after the implicit conversions allowed for operands. Two declarations clash if every operand could be converted, by the conversions allowed for operands, to the parameter types of both; for a binary operator this must hold for both operands. Declarations for (int, real) and (real, int) can therefore coexist. The Report calls clashing types firmly related. In practice the operand types must really differ, not merely in whether an operand is a reference, and a union is related to each of its members (Section 7.18); the compiler reports a violation as “firmly related”.

An operator can also be defined for arrays. The result of the following + is a new array, which is copied out of the function like any other value:

op + = ([] real a, b) [] real:
begin
   if LWB a /= LWB b orel UPB a /= UPB b then
      print (("bounds differ", newline)); stop
   fi;
   [LWB a : UPB a] real sum;
   for i from LWB a to UPB a do sum[i] := a[i] + b[i] od;
   sum
end;
[] real v = (1.5, 2.5, 3.5);
[] real w = v + [] real (1, 1, 1);
for i to UPB w do print ((fixed (w[i], 0, 1), " ")) od;
print (newline)
2.5 3.5 4.5

The second operand is an array literal, which must be annotated with its type: a literal is allowed only where its type is known, and the operand of an operator is not such a place (Section 7.12).

Since type names are only abbreviations, mode Meters = real does not create a type of its own, and an operator for Meters would be an operator for real. A record with a single field does create a distinct type, the “newtype” of current languages. The record types must have different field names, or they would be the same type:

mode Meters = struct (real m), Seconds = struct (real s);
proc meters = (real x) Meters: (Meters r; m of r := x; r);
proc seconds = (real x) Seconds: (Seconds r; s of r := x; r);
op + = (Meters a, b) Meters: meters (m of a + m of b);
op / = (Meters d, Seconds t) real: m of d / s of t;
Meters distance = meters (100) + meters (300);
Seconds time = seconds (50);
print ((fixed (distance / time, 0, 1), " m/s", newline))
8.0 m/s

A record literal needs at least two fields, so the functions meters and seconds build the values.

5.8 How an operator is chosen

When the compiler meets an operator, it chooses the declaration by the types of the operands. Operands are in a firm context (Section 2.10): a variable is dereferenced and a parameterless function is called, but an int is not widened to a real. An operator declared only for real operands therefore does not accept an int:

access Genie_Transput
begin
   op HALF = (real x) real: x / 2;
   print ((HALF 3, newline))
end
no-widening-op.a68:4:12: error: monadic operator HALF int has not been declared

The standard operators avoid this problem by declaring every combination of int and real operands. A program that wants the same convenience must do the same, or call the operator with a real operand. The Report calls the choice of the declaration the identification of the operator; current languages call it overload resolution.

The precedence belongs to the symbol, not to one of its declarations: all the meanings of + in a block have the same precedence, and a prio declaration changes it for all of them, the standard ones included. Like every other declaration, it holds only in the block that contains it:

print ((3 + 4 * 7, newline));
begin
   prio + = 7;              { now + binds as tightly as * }
   print ((3 + 4 * 7, newline))
end;
print ((3 + 4 * 7, newline))  { the standard precedence again }
        +31
        +49
        +31

Inside the inner block, + and * have the same precedence and are applied from left to right, so 3 + 4 * 7 is (3 + 4) * 7 = 49. After the block, + has its standard precedence 6 again. A block may declare the precedence of a symbol only once; a second prio for + in the same block is an error (“multiple declaration of priority”).

5.9 A complete program

The final program of this chapter defines a type of exact fractions and the arithmetic operators for it. The function rat reduces a fraction to lowest terms with the greatest common divisor and makes the denominator positive. A new operator // builds a fraction from two integers; it is given the precedence of /. The unary operator STR converts a fraction into a string.

access Genie_Transput
begin
   { Exact arithmetic with fractions. }
   mode Rat = struct (int num, den);
   proc gcd = (int a, b) int: (b = 0 | ABS a | gcd (b, a MOD b));
   proc rat = (int n, d) Rat:
   begin
      int g = gcd (n, d) * SIGN d;
      (n % g, d % g)
   end;
   op + = (Rat a, b) Rat:
      rat (num of a * den of b + num of b * den of a, den of a * den of b);
   op - = (Rat a, b) Rat:
      rat (num of a * den of b - num of b * den of a, den of a * den of b);
   op * = (Rat a, b) Rat: rat (num of a * num of b, den of a * den of b);
   op / = (Rat a, b) Rat: rat (num of a * den of b, den of a * num of b);
   op - = (Rat a) Rat: (-num of a, den of a);
   op +:= = (ref Rat a, Rat b) ref Rat: a := a + b;
   op STR = (Rat a) string:
      whole (num of a, 0) + (den of a = 1 | "" | "/" + whole (den of a, 0));
   prio // = 7;
   op // = (int n, d) Rat: rat (n, d);
   Rat sum := 0 // 1;
   for k to 6 do sum +:= 1 // k od;
   print (("1 + 1/2 + ... + 1/6 = ", STR sum, newline));
   print ((STR (3 // 4 * (2 // 3 - 1 // 6)), " ", STR - (6 // 8), " ",
           STR (1 // 2 / (1 // 4)), newline))
end
1 + 1/2 + ... + 1/6 = 49/20
3/8 -3/4 2

Note how the standard symbols +, -, * and / get a new meaning for the type Rat without losing their meaning for numbers, and how the unary and binary - are declared separately. Defining + does not define +:=: the program declares it separately, with a reference to the variable as its left operand and the variable as its result, like the standard +:=. The expression STR - (6 // 8) applies two unary operators, the minus first.

Exercises

The answers are at the end of the book.

  1. What is the type of each of these functions? (a) proc f = (real x, int n) real: x ** n (b) proc g = bool: random < 0.5 (c) proc h = (ref [] int a) void: a[1] := 0

  2. Write a function digit_sum that returns the sum of the decimal digits of a non-negative int, once with a loop and once recursively.

  3. Why does proc inc = (int n) void: n +:= 1 not compile, and how must it be written to increase the caller’s variable?

  4. Write a function apply_twice that takes a function of type proc (int) int and an int and applies the function twice. Call it with a function literal that doubles its argument.

  5. Declare an operator ABOVE so that a ABOVE b is true if a is greater than b, for int operands, with the precedence of >. What is the value of 1 + 2 ABOVE 2?

  6. With the operators of this chapter, what is SQUARE 2 MAX 3?

  7. Why does the assignment p := hello not call the function hello, although its value is discarded?

  8. In a block that contains prio + = 7, what is the value of 1 + 2 * 3?

  9. May op MAX = (int a, real b) real and op MAX = (real a, int b) real be declared in the same block?

  10. Write an operator * that multiplies a [] real by a real and returns a new array with the same bounds.

  11. A function month = (ref int day) string takes a day of the year, returns the name of its month and changes day to the day within that month. Why is print ((month (d), " ", d)) wrong, and how is it corrected?

  12. Write a function sum = (int lo, hi, proc (int) real term) real and use it to compute the sum of 1/k2 for k from 1 to 100 and the scalar product of two arrays v and w. Why can the second call not simply pass v[k] * w[k]?

Programming problems

  1. Write a function that returns the n-th prime number, and use it to print the first 20 primes.

  2. Solve the Towers of Hanoi recursively and print the moves for four discs.

  3. Write a function that finds a root of a function proc (real) real in an interval by bisection, and use it to compute the cube root of 2.

  4. Define a type Vector with three real fields and the operators +, -, * (scalar product) and a unary ABS (length).

  5. Extend the rational numbers of this chapter with the comparison operators = and <, and use them to sort an array of fractions.

  6. Merge sort. Sort an array by recursive merge sort, passing the halves to the recursive calls as slices of a ref [] int.

  7. Permutations. Print all permutations of the numbers 1 to n, and all ways of choosing k of them, with a recursive procedure that fills an array position by position.

  8. Plotting. Write a procedure that takes a function proc (real) real, an interval and a height, and plots the function with characters. Plot sin and a function literal.

  9. Horner’s rule. Write a function that evaluates a polynomial whose coefficients are given in an array with any lower bound, and count the multiplications compared with computing each power separately.

  10. The 91 function. McCarthy’s function is f(n) = n − 10 for n > 100 and f(f(n + 11)) otherwise. Compute it recursively for n from 1 to 110, and find a simple formula for its values.

  11. Monte Carlo. Estimate π by choosing random points in a square with random and counting those inside the circle, for 103, 104 and 105 points.

  12. Matrices. Declare +, * and *:= for [,] real, checking that the bounds fit.

  13. Resistors. Declare an operator PAR that combines two resistances in parallel, ab/(a + b), choose a precedence for it relative to + (resistances in series), and add an assigning form PARAB in the style of +:=. Compute a network of several resistors with one formula.

  14. A maze. Describe a maze by a function blocked = (int x, y) bool and find a way from the entrance to the exit with a recursive procedure that tries each direction, marks the cells it has visited, and backs out of dead ends. Print the path as the recursion returns, and explain why it comes out in reverse order.

  15. An evaluator. Evaluate integer expressions with + - * / and parentheses, given as a string, with mutually recursive functions for expressions, terms and factors that share a position variable.
