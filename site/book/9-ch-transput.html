9 Input and output

The programs so far used print and read on the standard output and the standard input. This chapter describes input and output in general: how a program reads and writes files, reads from and writes to strings, reacts to the end of the input and to bad data, converts numbers to text, and lays out its output precisely with formats. The Report calls input and output together transput.

The transput of the Report is a large part of its standard library, and the implementations provide it to different degrees. Algol 68 Genie provides nearly all of it; Section 9.12 lists what it lacks. For ga68 and a68j, the module Genie_Transput provides the unformatted part used in this chapter; formatted and binary transput are not available there, and the examples of those sections were run with Algol 68 Genie.

9.1 Books, channels and files

The Report distinguishes three things that current languages usually do not separate:

  • A book is the data itself, such as a file on disk, identified by a name. Its text is divided into pages, the pages into lines, and the lines into characters, and a position in a book is given by a page, a line and a character number.

  • A channel describes a kind of device and what can be done with it: stand_in_channel for reading, stand_out_channel for writing, stand_back_channel for both.

  • A file (here of type File) is what a program uses to read or write a book through a channel: a file handle or stream, in today’s terms. It records the current position in the book, the procedures to call when something unusual happens, and a few settings.

The procedure open (f, name, channel) connects the file f with an existing book; establish (f, name, channel) creates a new one, and create (f, channel) creates a new book without a name, a temporary file. These procedures return 0 on success. close (f) ends the connection, scratch (f) ends it and deletes the book, and reset (f) returns to the start of the book. The files stand_in and stand_out are open from the start; print (x) is short for put (stand_out, x), and read (x) for get (stand_in, x).

Implementation note.  In ga68 and a68j the type is called File and the channels and procedures are those of Genie_Transput, since the reserved word file of ga68 does not yet denote a usable type. In the Report and in Algol 68 Genie, the type is file. In the Report, establish has three more parameters, the number of pages, lines per page and characters per line of the new book; the implementations leave them out.

9.2 Reading and writing files

The procedures put and get write and read a list of values, like print and read, but on a given file. The following program writes five lines to a new file and then reads them back:

   File results;
   if establish (results, "squares.txt", stand_out_channel) /= 0 then
      print (("cannot create squares.txt", newline)); stop
   fi;
   for i to 5 do put (results, (i, " ", i * i, newline)) od;
   close (results);

   File data;
   if open (data, "squares.txt", stand_in_channel) /= 0 then
      print (("cannot open squares.txt", newline)); stop
   fi;
   on_logical_file_end (data, (ref File f) bool: goto done);
   do
      int n, square;
      get (data, (n, square));
      print ((whole (n, 0), " squared is ", whole (square, 0), newline))
   od;
done:
   close (data)
1 squared is 1
2 squared is 4
3 squared is 9
4 squared is 16
5 squared is 25

The reading loop has no condition: it ends when the input is exhausted. The procedure on_logical_file_end installs a procedure that the transput calls when a get reaches the end of the book; here it jumps out of the loop to the label done. Such procedures are the Report’s event routines; today they would be called callbacks or handlers. Section 9.4 describes them in general.

The predefined label stop ends the program; goto stop, or just stop, can be written anywhere.

Implementation note.  In Algol 68 Genie, establish returns 0 even if the file already exists; the error comes with the first put (“file exists”). The program above therefore fails when it is run a second time in the same directory. open with stand_out_channel opens an existing file for writing and empties it. A program that should work in both cases tries open first and calls establish only if that fails.

9.3 Reading the standard input

The same technique reads all of the standard input, however much there is. Numbers are separated by blanks and line breaks. One detail matters here: the event routine jumps to a label of the program’s block, so it lives only as long as that block (Section 7.16), whereas stand_in lives as long as the whole program. Installing the routine in stand_in itself would break the lifetime rule; the Report uses a case like this as its example. The program therefore copies stand_in into a local file variable and reads from that:

   { Sum all numbers on the standard input, however many there are. }
   real sum := 0;
   int count := 0;
   File input := stand_in;           { a copy, local to this block }
   on_logical_file_end (input, (ref File f) bool: goto finished);
   do
      real x;
      get (input, x);
      sum +:= x;
      count +:= 1
   od;
finished:
   print ((whole (count, 0), " numbers, sum ", fixed (sum, 0, 2), newline))
4 numbers, sum 11.25

with the input

1.5 2.5
3

4.25

The copy input reads the same data as stand_in: a File value contains references to the book and to the current position, which the copy shares, and its own event routines, which it does not share. The copy can therefore be given an event routine that lives only as long as the block, while reading continues where stand_in stands.

A number is read up to the first character that cannot belong to it: 12abc yields 12 and leaves abc for the next read, and 1,024 yields 1. Leading blanks and line breaks are skipped. A character is read as it is, a blank included; at the end of a line, the line break is skipped and the first character of the next line is read.

A string is read up to the end of the line; the line break itself is not read, and the next get of a string would yield an empty string at once. It is skipped with newline, which, like space, backspace and newpage, can appear in the list of get as well as of put. On input they skip the rest of the line, one character, and so on; on output they start a new line, move one position, and start a new page. A program that processes its input line by line reads a line, processes it, and then skips the line break:

   { Number the lines of the standard input. }
   int n := 0;
   File input := stand_in;
   on_logical_file_end (input, (ref File f) bool: goto finished);
   do
      string line;
      get (input, line);              { the rest of the line }
      n +:= 1;
      print ((whole (n, -3), "  ", line, newline));
      get (input, newline)            { skip the line break }
   od;
finished:
   skip
  1  Algol 68 was designed
  2  by IFIP Working Group 2.1.
  3  
  4  The Revised Report appeared in 1975.

The input was:

Algol 68 was designed
by IFIP Working Group 2.1.

The Revised Report appeared in 1975.

Pitfall.  The shorter get (input, (line, newline)) looks equivalent, but it loses the last line if the input does not end with a line break: newline then reaches the end of the input, the event routine jumps away, and the line that was just read is never printed. Text editors and programs do not always write a final line break.

The layout procedures are ordinary procedures of type proc (ref File) void. They can be called directly, as newline (stand_out), and a program can write its own procedure of this type and put it in a list, where put and get call it with the file:

proc indent = (ref File f) void: put (f, "    ");
print (("total:", newline, indent, "12 items", newline));
for i to 3 do print (i) od;
newline (stand_out);
print (("done", newline))
total:
    12 items
         +1         +2         +3
done

9.4 Events

An event routine is installed in a file for one kind of event. It receives the file and returns a bool. If it returns true, it reports that it has dealt with the event and the transput continues; if it returns false, the default action follows. A routine can also jump out, as in the examples above.

Installed with Called when Default action
on_logical_file_end the data of the book are exhausted error
on_physical_file_end the medium is full or exhausted error
on_line_end a line is exhausted newline
on_page_end a page is exhausted newpage
on_format_end a format is exhausted (Section [sec-format-list]) start it again
on_value_error a value cannot be read or written error
on_char_error a character cannot be converted error

The Report leaves the program undefined where the table says “error”; the implementations stop it with a message. Genie_Transput provides the logical end of the file and the value error. Algol 68 Genie provides all except on_char_error; a character that cannot be converted causes a value error.

A routine that returns true must really have dealt with the event, because the transput then continues at the same place. With Algol 68 Genie and Genie_Transput, a value error on input occurs when the text is not a number. (The Report calls the char error routine for a character that cannot belong to a number, and the value error routine for a number that cannot be converted.) If the routine only counts the error, the bad text is still there, and the next number fails in the same way:

string text := "12 x3 45 67";
File f;
associate (f, text);
make_term (f, " ");
int errors := 0;
on_value_error (f, (ref File g) bool:
   begin
      errors +:= 1;
      true                   { the error has been dealt with }
   end);
int a := -1, b := -1, c := -1, d := -1;
get (f, (a, b, c, d));
print ((whole (a, 0), " ", whole (b, 0), " ", whole (c, 0), " ",
        whole (d, 0), ", errors: ", whole (errors, 0), newline))
12 -1 -1 -1, errors: 3

prints 12 -1 -1 -1, errors: 3: one bad word spoiled all the following values. The routine must remove the cause, here by reading the bad word as a string:

string text := "12 x3 45 67";
File f;
associate (f, text);
make_term (f, " ");
int errors := 0;
on_value_error (f, (ref File g) bool:
   begin
      errors +:= 1;
      string bad;
      get (g, bad);          { skip the word that is not a number }
      true                   { the error has been dealt with }
   end);
int a := -1, b := -1, c := -1, d := -1;
get (f, (a, b, c, d));
print ((whole (a, 0), " ", whole (b, 0), " ", whole (c, 0), " ",
        whole (d, 0), ", errors: ", whole (errors, 0), newline))
12 -1 45 67, errors: 1

which prints 12 -1 45 67, errors: 1. In the same way, a logical file end routine that returns true without having made more data available is called again, according to the Report; the implementations call it once and continue, and the value that was to be read is then not meaningful. Such a routine should jump away, as in the examples above, or return false.

9.5 Strings as files

The procedure associate (f, s) connects a file with a string variable instead of a book. Reading then takes the characters from the string, and writing adds to it. This converts between numbers and their textual form with all the facilities of the transput:

string text := "3 4 5";
File f;
associate (f, text);               { f now reads from text }
int a, b, c;
get (f, (a, b, c));
print ((whole (a * a + b * b - c * c, 0), newline));

string line := "";
File g;
associate (g, line);               { g now writes into line }
put (g, ("a = ", whole (a, 0), ", c = ", whole (c, 0)));
print ((line, newline))
0
a = 3, c = 5

Implementation note.  In the Report, associate connects a file with an array of arrays of arrays of characters (pages, lines, characters) of fixed size, and writing overwrites it from the start. Algol 68 Genie and Genie_Transput use a ref string instead and append to it, which is what programs need in practice.

9.6 Terminators and other settings

A string read with get ends at the end of the line. The procedure make_term (f, s) makes it end also at every character of the string s; the terminating character itself is not read. The complete program at the end of this chapter uses it to read a name that ends at a blank.

A file can be asked what it allows: get_possible (f), put_possible (f), bin_possible (f), reset_possible (f) and set_possible (f) return a bool. After a file has been written, reset returns to the start so that it can be read; reading and writing cannot simply alternate.

The Report provides further procedures, which Algol 68 Genie does not have: the current position (char_number, line_number, page_number) and the setting of it (set_char_number and a set with page, line and character), a new name for a book (reidf), and a translation table for characters (make_conv). A program that needs the current line number counts the lines itself. Genie_Transput provides, besides make_term, the functions eof and eoln of Algol 68 Genie, which test for the end of the file and of the line.

9.7 Printing arrays and records

put and print accept arrays and records, not only single values, provided that they contain no references, functions or unions. They are broken down into their elements and fields, which are printed one after the other; the Report calls this straightening. An array of records thus prints the fields of every element:

mode Point = struct (int x, y);
[] Point path = ((1, 2), (3, 4));
print ((path, newline))
                  +1                  +2                  +3                  +4

get straightens in the same way: get (f, m) for a [2,3] int variable m reads six numbers into it, row by row. For input the Report is stricter: apart from a string variable itself, the variable may contain no resizable arrays, so a record with a string field or an array of strings cannot be read with one get.

Implementation note.  Genie_Transput straightens arrays of the primitive types but not records (Section 4.11), and its get does not accept arrays; this example was run with Algol 68 Genie, whose int has 64 bits and is therefore printed in a wider field. Algol 68 Genie also reads a record with string fields with one get.

9.8 Converting numbers to text

The procedures whole, fixed and float of Section 2.14 convert a number into a string of a given width, which is the usual way to lay out numbers without formats:

  • whole (i, w) writes an integer in a field of width |w|. If w is positive, a sign is always written; if it is negative, only a minus sign. w = 0 gives the shortest string.

  • fixed (x, w, d) writes a real with d digits after the point, in a field of width |w|, with the same rules for the sign.

  • float (x, w, d, e) writes a real in scientific notation with d digits after the point and an exponent of e digits.

print (("[", whole (42, 6), "] [", whole (42, -6), "] [", whole (-42, 0),
        "] [", whole (123456, 3), "]", newline));
print (("[", fixed (3.14159, 8, 3), "] [", fixed (3.14159, -8, 3),
        "] [", fixed (3.14159, 6, 4), "] [", fixed (0.015, 0, 4), "]", newline));
print (("[", float (31415.9, 10, 3, 2), "] [", float (31415.9, -10, 3, -2),
        "]", newline))

prints

[   +42] [    42] [-42] [***]
[  +3.142] [   3.142] [+3.142] [.0150]
[+31.416e+3] [ 31.416e 3]

A number that does not fit is not given a wider field, unlike C’s printf: whole (123456, 3) yields three asterisks. fixed first gives up digits after the point, so that fixed (3.14159, 6, 4) yields +3.142; only when the integral part does not fit either does it yield asterisks. fixed writes no zero before the point of a number below 1 if the width is 0 (.0150). float chooses the exponent so that as many digits as possible stand before the point.

9.9 Formatted output

For complete control over the layout, the Report provides formats, a small language of their own, comparable to the format strings of printf in C or of Fortran’s FORMAT statement. A format text is written between dollar signs. The procedure printf takes a list that begins with a format and continues with the values; putf does the same for a given file, and readf and getf read according to a format.

int n = 42;
real x = 3.14159;
printf (($"[" 5d "]" l$, n));          { five digits, leading zeros }
printf (($"[" 5zd "]" l$, n));         { leading zeros suppressed }
printf (($"[" -4zd "]" l$, -n));       { a sign if negative }
printf (($"[" zzd.dd "]" l$, x));      { fixed point }
printf (($"[" d.3de+2d "]" l$, x * 1000));   { floating point }
printf (($"[" 3a "]" x b l$, "abc", true))
[00042]
[    42]
[-   42]
[  3.14]
[3.142e+03]
[abc] T

A format consists of pictures, each of which describes how one value is printed, separated by commas. A picture is made of frames:

Frame Meaning
d a digit
z a digit, printed as a blank if it is a leading zero
+, - a sign: always, or only if negative
. the decimal point
e the exponent marker of a floating-point number
a a character
b a truth value (T or F)
g a value in its standard layout, as print would print it

A number before a frame repeats it: 5d is five digits and 3zd is three suppressible digits followed by one that is always printed. Between the frames, insertions add text: a string in quotes is printed as it is, x prints a blank, l ends the line and p the page, and k moves to a given column. They too can be repeated, as in 2x or 3"-".

One picture, one value

Everything between two commas is one picture, and one picture prints one value, however many frames it has:

printf (($"a = " 2d ", b = " 2d l$, 1));      { one picture: one value }
printf (($"a = " 2d, ", b = " 2d l$, 1, 2))   { two pictures }

prints

a = 00, b = 01
a = 01, b = 02

In the first format, 2d ", b = " 2d is a single picture of four digits with some text in the middle, and it prints the single value 1 as 0001 with the text inserted. This is easy to get wrong and hard to see; when a format prints something strange, the commas are the first thing to check.

Where the sign goes

A sign frame before the digits puts the sign at the left edge of the field. A sign frame after the z frames lets it move to just before the first printed digit:

for i to 3 do
   int n = (i | 42, -42, -7);
   printf (($"[" -4zd "] [", 4z-d "] [", 4z+d "] [", +4d "]" l$, n, n, n, n))
od

prints

[    42] [    42] [   +42] [+0042]
[-   42] [   -42] [   -42] [-0042]
[-    7] [    -7] [    -7] [-0007]

A negative value in a picture without a sign frame is a value error.

Choices, general patterns and other kinds of values

A truth value can be printed with two strings of the program’s choice, b("yes", "no"), and an integer between 1 and n can select one of n strings with c("one", "two", ...). Both make it easy to print plurals and names:

for n from 0 to 2 do
   printf (($g(0) " file" b("", "s") " found" l$, n, n = 1))
od;
for month from 1 to 3 do
   printf (($c("January", "February", "March") ", " g(0) l$, month, month))
od;
printf (($b("yes", "no") ", " b l$, 3 > 2, 3 > 4))

prints

0 files found
1 file found
2 files found
January, 1
February, 2
March, 3
yes, F

The general pattern g prints a value as print would. With parameters, it prints a number like the conversion procedures of Section 9.8: g(w) like whole, g(w, d) like fixed, and g(w, d, e) like float. The parameters can be any integer expressions. A bits value is printed in base 2, 4, 8 or 16 with a picture such as 2r8d or 16r4d:

real x = 1234.5678;
printf (($g l$, x));
printf (($g(10) "|" g(-10, 2) "|" g(-12, 3, 2) l$, 42, x, x));
int w = 9;
printf (($g(w, w - 6) l$, x));            { the parameters can be computed }
bits b = 2r1011;
printf (($2r8d, " " 16r4d l$, b, 16rbeef))

prints

+1.23456780000000e  +3
       +42|   1234.57| 1234.568e+0
+1234.568
00001011 beef

The first line shows the standard layout of a real in Algol 68 Genie, whose real has 64 bits.

A string is printed with a frames, one per character, and the number of frames must equal the length of the string; insertions between the frames are allowed:

printf (($a". "5a l$, "JSmith"));          { one string, split by an insertion }
printf (($"[" 5a "]" l$, "Algol"));
printf (($"[" 5a "]" l$, "Al"))           { wrong length: a run-time error }
J. Smith
[Algol]
5        printf (($"[" 5a "]" l$, "Al"))           COMMENT wrong length: a run-time error COMMENT
                        1                                                                        
a68g: runtime error: 1: error transputting [] CHAR value, in [] "SIMPLOUT" collateral-clause starting at "(" in this line.

prints J. Smith and [Algol], and then stops with an error, since "Al" has only two characters for five frames. A string of variable length is printed with g or with the computed repetition of the next section.

A part of a format can also be chosen when the program runs. The format pattern f(...) contains an expression that yields a format, and inserts that format in its place:

for n to 3 do
   printf (($g(0), x f(n = 1 | $"item"$ | $"items"$) l$, n))
od;
printf (($"Smith""Jones" l$));
printf (($"Smith" 1"Jones" l$))

prints

1 item
2 items
3 items
Smith"Jones
SmithJones

Pitfall.  Two string insertions with nothing between them are one string: as in a string literal, a doubled quote stands for a quote character, so "Smith""Jones" prints Smith"Jones, as the fourth line shows. A repetition count, even 1, keeps them apart. Algol 68 Genie also accepts a space between them, the Report does not.

Repetition and columns

A repetition can be computed while the program runs: in n (k) (...), the part in parentheses is repeated k times, which suits arrays of any size. An integer value is printed through a real picture as a real number:

format row = $3zd, 2x zd.ddd, 2x zzzd.d l$;
printf (($"   n   sqrt n    n ** 3" l$));
for n to 5 do printf ((row, n, sqrt (n), n ** 3)) od;
[] int v = (7, 11, 13, 17);
printf (($"values:" n (UPB v) (x 2d) l$, v))
   n   sqrt n    n ** 3
   1   1.000     1.0
   2   1.414     8.0
   3   1.732    27.0
   4   2.000    64.0
   5   2.236   125.0
values: 07 11 13 17

The insertion k moves to the column given by its repetition count, which can also be computed. That is enough for a simple plot:

for i from 0 to 8 do
   real x = i * pi / 8;
   int column = 10 + ROUND (20 * sin (x));
   printf (($zd.dd, n (column) k "*" l$, x))
od

prints

 0.00    *
 0.39            *
 0.79                  *
 1.18                      *
 1.57                        *
 1.96                      *
 2.36                  *
 2.75            *
 3.14    *

How the values and the format are matched

The values of the list are matched with the pictures of the format one by one. When the format is exhausted and values remain, it starts again from the beginning: printf (($2d l$, 1, 2, 3)) prints three lines. This is the default action of the event on_format_end. A list may contain several formats, each of which applies to the values after it. The layout procedures newline and space cannot appear in the list of printf; the insertions l and x take their place.

A format is a value of the type format and can be stored in a variable, passed to a procedure, or chosen at run time: a proc (int) format can return different formats for different cases. A format that computes a repetition from a local name, n (digits) d, is subject to the lifetime rule (Section 7.16) like a function, and cannot leave the block of digits.

Implementation note.  In the Report, the rest of a format that is not used up when the list ends waits for the next putf on the same file. Algol 68 Genie stops the program instead (“number of pictures does not match number of arguments”): the values must use the format up to its end.

9.10 Formatted input

readf and getf read according to a format. Every frame reads one character position: a picture 3zd reads four characters, and a z frame accepts a blank as a zero. The characters of a literal insertion such as "-" must be present in the input and are read over; x skips one character. This makes it easy to read data in fixed columns, such as the records of this file:

Ann Smith  2024-03-15  82
Bob Jones  2023-11-02 100
Cleo Grant 2024-01-30   7
   format record = $10a, x 4d, "-" 2d, "-" 2d, 3zd l$;
   File input := stand_in;
   on_logical_file_end (input, (ref File f) bool: goto done);
   do
      string name; int year, month, day, score;
      getf (input, (record, name, year, month, day, score));
      printf (($10a, x 2d, "." 2d, "." 4d, 5zd l$, name, day, month, year, score))
   od;
done:
   skip

prints

Ann Smith  15.03.2024    82
Bob Jones  02.11.2023   100
Cleo Grant 30.01.2024     7

The pictures "-" 2d skip the dash and read the month. The 10a reads exactly ten characters, the blanks of a short name included. A field that is one character too short or too long shifts every field after it: with 4zd for the score, which reads five characters, the program stops at the first record with an error.

9.11 Binary transput

The procedures put_bin and get_bin write values to a file and read them back in an internal, binary form, without conversion into characters. A file written this way can only be read back by a program that reads the same types in the same order:

File f;
if establish (f, "data.bin", stand_back_channel) /= 0 then stop fi;
put_bin (f, (42, 3.5, "xyz"));
reset (f);                                    { back to the start }
int n; real x; [1:3] char s;
get_bin (f, (n, x, s));
print ((whole (n, 0), " ", fixed (x, 0, 2), " ", s, newline));
close (f)
42 3.50 xyz

The channel stand_back_channel allows both reading and writing, and reset returns to the start of the file before reading. Binary and character transput cannot be mixed on one sequential file until it is reset; Algol 68 Genie enforces this.

Binary transput was meant for intermediate files that a program writes and reads again. Such a file does not need a name, and it should disappear when the program no longer needs it. create and scratch do exactly that:

File scratch_file;
if create (scratch_file, stand_back_channel) /= 0 then stop fi;
for i to 5 do put_bin (scratch_file, i * i) od;
reset (scratch_file);                         { back to the start }
int sum := 0;
for i to 5 do int n; get_bin (scratch_file, n); sum +:= n od;
scratch (scratch_file);                       { close and delete }
print (("sum of squares ", whole (sum, 0), newline))
sum of squares 55

9.12 What Algol 68 Genie lacks

Algol 68 Genie provides nearly all of the Report’s transput. The exceptions, apart from those already mentioned, are:

  • the position enquiries char_number, line_number and page_number, set_char_number, reidf, make_conv and the event on_char_error;

  • set moves relative to the current position, with one parameter, instead of to a given page, line and character;

  • the insertion k cannot move back to an earlier column, and backspace and the insertion y cannot be used on stand_out;

  • a z frame after a d frame always prints its digit, where the Report suppresses some zeros in date-like pictures; pictures with only d frames after the first are printed the same everywhere;

  • the format is not kept for the next call of putf (Section [sec-format-list]).

9.13 A complete program

The final program reads a file of names and marks and prints a report. The file marks.txt contains:

Ann 72 85 90
Ben 88 79 81
Cleo 95 91 70
Dan 60 75 68
access Genie_Transput
begin
   { Read names and marks from a file and print a report. }
   File data;
   if open (data, "marks.txt", stand_in_channel) /= 0 then
      print (("cannot open marks.txt", newline)); stop
   fi;
   make_term (data, " ");                  { a name ends at a blank }
   on_logical_file_end (data, (ref File f) bool: goto done);
   int students := 0;
   real class_total := 0;
   print (("name      average", newline));
   do
      string name;
      int a, b, c;
      get (data, (name, a, b, c, newline));
      real average = (a + b + c) / 3;
      print ((name, " " * (10 - UPB name), fixed (average, -7, 2), newline));
      students +:= 1;
      class_total +:= average
   od;
done:
   close (data);
   print (("class     ", fixed (class_total / students, -7, 2), newline))
end

make_term (data, " ") ends a name at the first blank, so that get reads the name and then the three numbers. The newline at the end of the list skips the line break, so that the next name starts at the beginning of the next line. The expression " " * (10 - UPB name) pads the name to ten characters.

Programming problems

  1. Line numbers. Copy a text file to another file with a line number in front of each line, and start a new page with a page number after every 50 lines.

  2. Word count. Count the characters, words and lines of the standard input, like the Unix program wc. Make sure that a last line without a line break is counted.

  3. Exam results. Each line of a file holds a student number of 6 digits, a name in 20 columns and three marks of 3 digits. Print a line per student with the name, the average with one decimal, and passed or failed (an average of at least 50 and no mark below 30 passes) chosen with a b(...) pattern, with one getf and one printf per student.

  4. Column totals. Read a table of numbers separated by commas, with an unknown number of rows, and print it with a format, with a total for each column.

  5. Bad records. Read records of a fixed layout with getf, and install an on_value_error routine that prints the number of each bad record and skips it.

  6. Bank statement. Read transactions (date, text, amount) and print a statement with a running balance, the amounts in a column with a floating sign or with b("CR", "DR"), and a heading on every page.

  7. A calendar. Print the calendar of a month, with the name of the month chosen by a c pattern and the first week indented with a computed repetition.

  8. Amounts in words. Print an amount of money below one million in words, as on a check, using choice patterns for the units, tens and hundreds.

  9. Justification. Read a text and print it with lines of a given width and straight margins on both sides, by distributing extra blanks between the words as evenly as possible. The last line of a paragraph keeps a ragged right margin.

  10. The last lines. Print the last n lines of the standard input, which may be of any length, numbered with whole.

  11. Merging. Write two sorted sequences of numbers to temporary files made with create, reset them, merge them onto the standard output, and scratch them.

  12. Number conversion. Write a procedure that converts a real into a string with a given number of significant digits, using associate or float.

  13. Announcements. Given the children of a family with their names, sexes and years of birth, print sentences such as “Ann is the eldest of three children” or “Tom is the only son”, choosing the words with b(...), c(...) and f(...) patterns in a single printf per child (Algol 68 Genie).
