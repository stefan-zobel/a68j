1 Introduction

1.1 Algol 68

Algol 68 was designed by Working Group 2.1 of the International Federation for Information Processing (IFIP), the group that had earlier produced Algol 60. The language was defined in the Report on the Algorithmic Language Algol 68 of 1968, published in 1969 [2]; a revised definition, the Revised Report [1], was published in 1975. This book describes the language of the Revised Report, which is what all current implementations follow. Lindsey’s history of the language [8] tells how it came about.

Algol 68 is a compiled, statically typed, imperative language. Its designers aimed for a small number of general concepts that combine without special cases, a property they called orthogonality. The result is a language in which, for example, a block, an if and a case are all expressions with a value, any type can be the element type of an array or the result type of a function, and a function is a value like any other.

1.2 A first program

Here is a complete program:

access Genie_Transput
begin
   print (("Hello, world!", newline))
end
Hello, world!

The line after the program is its output. The program consists of a block, the text from begin to end. The block contains one call of the procedure print, which writes its argument to the standard output. The argument is a list of two items in parentheses: the string "Hello, world!" and newline, which ends the line. That is why there are two pairs of parentheses: the outer pair belongs to the call, the inner pair encloses the list. A call with a single item needs only one pair, as in print (newline).

The first line, access Genie_Transput, makes print and the other input and output procedures available. The Revised Report includes print in the standard library, and Algol 68 Genie provides it that way. The standard library of ga68 provides only low-level input and output, and a68j follows ga68. The module Genie_Transput fills the gap: it provides the procedures of the Report that this book uses. It comes with a68j, and its source can be compiled with ga68 as well. Every program in this book that reads or writes begins with this line; with Algol 68 Genie, the line is left out. Modules, a GNU extension of the language, are described in Appendix E.

1.3 Compiling and running

With a68j, a program is compiled and run in one step:

$ java -jar a68j-backend.jar -run hello.a68
Hello, world!

With ga68, the module Genie_Transput is compiled once, and the program is compiled and linked with it:

$ ga68 -c genietransput.a68
$ ga68 -I. hello.a68 genietransput.o -o hello
$ ./hello
Hello, world!

The source of the module, genietransput.a68, comes with a68j.

1.4 Reserved words, type names and operators

Some words in an Algol 68 program are reserved words: begin, end, int, if and some sixty others. In this book they are printed in bold, a tradition that goes back to the Report, where these words are written in a typeface of their own. In a source file they are written in lower case.

How the reserved words are told apart from other words in a source file is called stropping (stropping). Several conventions have been used. This book uses the default convention of ga68, which is also understood by a68j:

  • reserved words are written in lower case: begin, int;

  • a type name that the program declares begins with a capital letter: Node, Point;

  • operators that are words are written in capitals: ABS, MOD, or a user-defined MAX;

  • everything else, such as the names of constants, variables and procedures, is written in lower case, with digits and underscores: max_value, x2.

Algol 68 Genie uses a different convention by default, in which reserved words, type names and word operators are written in capitals (BEGIN INT n = 1; ... END) and names may contain spaces.

1.5 A second program

The next program computes the area and the circumference of a circle:

access Genie_Transput
begin
   { The area and the circumference of a circle. }
   real r = 2.5;
   real area = pi * r ** 2;
   real circumference = 2 * pi * r;
   print (("radius        ", fixed (r, 0, 2), newline));
   print (("area          ", fixed (area, 0, 2), newline));
   print (("circumference ", fixed (circumference, 0, 2), newline))
end
radius        2.50
area          19.63
circumference 15.71

The text between braces is a comment. The program declares three names for values: r for the radius, and area and circumference for the results; pi is a constant of the standard library. The operator ** raises to a power. The procedure fixed converts a number into a string with a given number of digits after the decimal point; the 0 asks for a string just as wide as needed. All of this is explained in the next chapter.
