Appendix A: The standard library

This appendix lists the parts of the standard library of the Revised Report that this book uses, by topic. The Report defines many of them for every size of a type; the tables show the plain size, and the long and short versions follow the rules of Section 6.2. Names written with underscores here, such as max_int, are written with blanks in the Report and in Algol 68 Genie (max int).

Types

Type Values
int, real, bool, char the primitive types (Chapter 2)
string flex [1:0] char (Chapter 7)
compl complex numbers, a record of two real fields (Chapter 6)
bits, bytes bit sets and byte strings (Chapter 6)
sema semaphores (Chapter 8)
file, channel, format transput (Chapter 9)
void no value

Operators

The binary operators of the library with their precedences. Every unary operator binds more tightly than every binary one.

Precedence Operator Operands
9 I int or real; builds a compl
8 ** int, real or compl base, int exponent
8 UP, DOWN bits and int: shift (also SHL, SHR)
8 LWB, UPB int (the dimension) and an array
7 * numbers; int and string (repetition)
7 / numbers; the result is never int
7 %, OVER int: integer division
7 %*, MOD int: remainder
7 ELEM int and bits or bytes
6 +, - numbers; + also joins strings and characters
5 <, <=, >=, > numbers, characters, strings, bits (<=, >=)
4 =, /= all primitive types, compl, bits, strings
3 AND bool, bits
2 OR bool, bits
1 +:=, -:=, *:=, /:=, %:=, %*:= a variable and a value
1 +=: a string or character and a string variable (prepend)

The word forms PLUSAB, MINUSAB, TIMESAB, DIVAB, OVERAB, MODAB and PLUSTO may be used instead of the compound assignment symbols, and EQ, NE, LT, LE, GE, GT instead of the comparisons.

The unary operators:

Operator Meaning
-, + negation, identity
ABS absolute value; code of a char; int value of bits; 1 or 0 for a bool
SIGN, ODD sign of a number; whether an int is odd
ROUND, ENTIER nearest int, largest int not greater
REPR the character with a given code
NOT negation of bool or bits
BIN bits from an int
RE, IM, ARG, CONJ parts of a compl
LENG, SHORTEN conversion to the next longer or shorter size
LWB, UPB bounds of the first dimension
LEVEL, UP, DOWN semaphores

Constants

Constant Meaning
pi π
max_int, max_real the largest int and real

blank, null_character, flip, flop the characters " ", code 0, "T", "F"

Procedures

Procedure Meaning
